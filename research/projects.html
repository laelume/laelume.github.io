Projects

Every package, pipeline, and side study that serves the research, grouped by the part of the problem it addresses. ANVO (ANimal VOcalization) is the umbrella name for the whole codebase.

Shared conventions run through all of it: no hardcoded paths (everything resolves through a YAML path configuration), a strict split between per-run visual outputs and persistent artifacts that ship with the code, verbose logging behind a flag, fallback methods and experimental features tagged inline so temporary decisions can be found later, and a first docstring line on every function that a small utility parses to build documentation.

Identity and description

Turning a segmented syllable into numbers, shapes, labels, and eventually a guess at which bird produced it.

sylpipe: the core identity pipeline

Status: active; the centre of the codebase

Builds the master syllable table from audio, onset-offset annotations, and contour changepoint files; computes per-syllable and per-sequence metrics; and runs the classification methods. Organised as experiments/<model>/<experiment>/ so that every run is reproducible from its configuration.

  • Elastic shape analysis on contours via SRVF: alignment, Karcher means, tangent-space principal components, phase-amplitude separation. A GPU path replaces a 45-minute CPU distance matrix. Results are cached by content hash so nothing is recomputed unnecessarily.
  • A prototype-based Karcher-mean dictionary was tried and set aside in favour of a continuous tangent-PCA shape code, with the earlier attempt kept as a design note for comparison.
  • Classification: PCA plus nearest-neighbour or support-vector machine (the 88 percent baseline), an SRVF-kernel support-vector machine, and a PyTorch Lightning classifier head on Perch embeddings.
  • Syllable-type discovery: non-negative matrix factorisation at syllable and sequence level, UMAP with HDBSCAN, and Hungarian matching of templates across birds.
  • Cross-method evaluation with an interactive HTML export: a UMAP map where each point shows its spectrogram on hover.
  • Balanced five-class proxy labels built by binning a one-dimensional embedding of combined length and shape distances, used to sanity-check classifiers before real labels are trusted.

vocal_metrics: the metrics registry

Status: active; subject of the framework paper

A path-agnostic package that defines quantitative vocal metrics in a YAML registry and computes them with a small metric engine. Syllable-level families cover temporal, frequency, time-frequency, trend, and harmonic intensity measures; sequence-level families cover temporal, frequency, bandwidth, and positional measures. The paper describing this framework is written directly against the registry so that prose never outruns implementation. Power spectral density metrics and compositional descriptors (type counts and entropies) are queued for a later revision.

Pretrained embeddings and active learning probes

Status: exploratory, feeding the classifier work

  • Perch 2.0 (Google DeepMind) embeddings extracted through ONNX for every syllable, used both for classification and for the interactive UMAP maps.
  • A CLAP zero-shot pipeline with per-chunk caching and checkpoint resumption.
  • Active learning probes using a Parzen-window classifier to ask which syllables would be most informative to label next.
  • An open question on whether BirdNET or a torch-native alternative such as AVES is the better backbone for a torch training loop.

KiwiNet translation

Status: complete

A full translation of the Bedoya and Molles (2021) MATLAB codebase for kiwi censusing and individual identification into Python: sixteen files covering the KiwiNet convolutional network, joint clustering, and the identification scripts, plus a generic .mat to .npy converter. Every translation caveat is collected in a numbered flags block at the bottom of each file, and genuine discrepancies between the original scripts are preserved and flagged rather than silently unified.

Individual-labelled bird dataset catalogue

Status: reference document

A systematic catalogue of fourteen publicly available bird datasets with individual-level labels (from Zenodo, OSF, and Figshare), along with related mammal corpora, assembled so that methods developed on kiwi can later be tested on other species.

Finding calls and syllables

Everything upstream of identity: finding kiwi in long recordings, cutting calls into syllables, and locating the changepoints inside a syllable.

Binary kiwi detector and xeno-canto harvester

Status: working; synthesis-based data augmentation scoped

A presence detector built from Perch embeddings and a logistic-regression head. Training data comes from field annotations (AviaNZ-style files, both legacy and current segment formats, with a windowed cache and content-hash identity) and from a standard-library-only harvester that pulls species-filtered recordings from the xeno-canto API and converts them with ffmpeg. A redesign is scoped that mixes isolated syllables onto real background recordings to widen the training set.

Two-head gap detector

Status: active; combined decoder in progress

Finds the gaps between syllables in raw field recordings, which is the hard part of automatic segmentation: not every silence is an inter-syllable gap, and kiwi syllable spacing varies. A shared spectral and dilated temporal convolutional trunk feeds two heads, one predicting gap regions and one predicting syllable activity, and the decoder keeps a gap only when syllable activity flanks it on both sides.

  • Separator baseline: F1 of 0.753 (precision 0.684, recall 0.837) at 150 ms tolerance, from a checkpoint that is preserved as the reference.
  • Supervision is small and honest: 442 positive separators across 23 files, 62 hard negatives, and 28 syllable intervals from one file, so the syllable head's in-sample score is not yet a generalisation claim.
  • TweetyBERT is being assessed as a pretrained backbone, with the open question of whether its pretraining band covers the kiwi range of roughly 1600 to 2900 Hz.
  • Experiment tracking and checkpoint provenance in Weights and Biases, after checkpoint lineage confusion proved costly.
  • A companion review tool lets a person accept, reject, or merge predicted separators directly on a spectrogram.

phonemepipe: changepoints inside a syllable

Status: notebook scaffold; training loop being wired

A small recurrent network that predicts, frame by frame, whether a frequency-jump boundary occurs inside a syllable. Targets come from the existing changepoint annotations; the individual bird is a grouping key for the train-test split, never a feature. Training uses ten-frame windows with carried hidden state. An active learning variant with a YAML configuration and a Parzen-window classifier chooses which syllables to annotate next.

subseq: changepoints and factorisation over sequences

Status: working; being repackaged

Twelve scripts for changepoint detection (PELT and dynamic programming) and non-negative matrix factorisation with pooling at syllable, individual, sequence, collection, or global level, plus batch processing with checkpoints. Includes a frame-theoretic view of changepoint detection and time-normalised comparison of factor activations using SRVF distances. This is the toolkit the syntax chapter will build on.

Instantaneous frequency contours and alignment

Status: working; offsets verified interactively

Automatic contour extraction from syllable audio using instantaneous frequency (the Iatsenko method), overlaid on spectrograms for parameter sweeps. A systematic investigation found and corrected two alignment mismatches between the extractor and the spectrogram grid (a half-window time shift and a half-bin frequency offset). An interactive notebook widget lets a person nudge a contour with arrow keys or the mouse and record per-file offsets. Onset-energy and PESTO pitch-confidence approaches were tried first and rejected for kiwi frequencies.

AviaNZ command-line extensions

Status: complete

Extensions to the AviaNZ bird-call analysis tool: GPU inference with a flag to disable it, automatic detection of the installed CUDA driver version, and a configurable directory for saved annotations.

Synthesis and generation

Going the other way: from a few parameters to a realistic call.

pavo: parametric pitch models

Status: active; fitting jobs running on the cluster

Fits kiwi syllable contours with a small number of sigmoid or Heaviside transitions, each with a time, an amplitude, and a steepness. A kiwi syllable typically needs two or three: a rise at onset, one or two plateaus, and a fall at offset. The fitted parameters are physically meaningful, compact, and double as synthesiser controls. Basis shapes and a stepped variant are defined in a pitch-model module, and fitting runs as batch jobs on the Rāpoi high-performance computing cluster.

Synthetic datasets and PAM labelling

Status: archetype set built; labelling pipeline scoped

A synthetic syllable dataset built from ten archetypes (tonal, linear rising and falling, logarithmic variants, sinusoidal, and step-shaped) used to test segmentation and classification methods under known ground truth. A separate four-stage pipeline for labelling passive acoustic monitoring recordings is scoped for eventual dataset publication, with the single-label versus multi-label schema identified as the gating decision and random sampling required alongside detector-based selection to avoid bias.

Phase-preserving time stretching

Status: shipped as a browser tool (timewarp-sync)

A harmonic-agnostic approach to stretching bird vocalisations in time without destroying phase relationships, built for the fast frequency modulation and mixed tonal-noisy content that defeat standard phase vocoder and PSOLA methods. Available as a tool on the landing site.

Tools and infrastructure

The software that makes the research repeatable, by this project and hopefully by others.

yaaat: Yet Another Audio Annotation Tool

Status: stable desktop tool; mobile port started

A five-tab annotation interface for bioacoustics: changepoint, peak, harmonic, and binary annotators, plus batch views. Designed around one principle: every control that changes what is on screen (FFT size, hop, overlays, algorithm choice) is surfaced as an immediate button, never hidden in a dialog. A feature comparison against Raven Pro, Audacity, Sonic Visualiser, Praat, AviaNZ, and BirdNET applies exactly that standard.

  • Modular core/ and tabs/ architecture with a shared base layer and a bounding-box annotation schema.
  • Command-line entry points for audio and annotation directories; when the annotation directory changes at runtime, prior annotations for the open file appear as grey dots with a keep-new, keep-old, or merge dialog.
  • Multi-format annotation input and output, peak snapping, drag-correction of detections, and multiple contour extraction modes.
  • A port to Android tablets is underway, starting with the changepoint annotator and bounding boxes.

SpectroVizard

Status: working editor extension

A zero-dependency VSCodium extension that renders spectrograms in a webview with a pure-JavaScript FFT and the Web Audio API, with the same wheel navigation and zoom conventions as yaaat and audio playback with a playhead.

pysoniq

Status: published on PyPI

A lightweight, cross-platform audio library used throughout the ecosystem for loading, lazy segment reading, playback, and signal-processing primitives. Librosa dependencies were replaced across the codebase in its favour. Also hosts the phase-space attractor module described under exploratory methods.

jellyfish and tranche

Status: in daily use

jellyfish is the notebook utility layer: dated per-run output directories, timestamps, and the helpers that keep visual artifacts separate from shippable data. tranche is a package for slicing audio according to annotations from AviaNZ, Raven, Audacity, and spreadsheet formats through a common parser interface.

Documentation and compute

Status: documentation builds locally; cluster in use

  • A single Sphinx tree documents all eight ANVO packages (pysoniq, yaaat, sylpipe, subseq, jellyfish, multimapper, models, vocal_metrics), with API pages regenerated automatically on every build and versions read from git tags, configured for Read the Docs.
  • The Rāpoi cluster at Victoria University of Wellington (Slurm, A100 GPUs) runs the heavy shape-analysis and fitting jobs, with a conda environment recreated from an exported file and batch templates for training.
  • Three-branch git layout per repository (local development, public development, main), with a mirrored bare-repository backup on a separate drive.

Exploratory methods

Ideas tried because they might expose structure the standard methods miss. Some will make it into the thesis; some are recorded so they are not tried twice.

Topological data analysis on spectrograms

Status: experimental

  • Persistent homology on spectrograms treated as cubical complexes, and Ball Mapper on syllable point clouds with animated sweeps over the radius parameter.
  • MEAMD (meadow): nested morphological openings at geometrically increasing scales, followed by sublevel-set filtration and clustering. Running at four scales rather than the motivated seven because of memory limits.
  • multimapper: the Mapper algorithm with spectral centroid as the lens function and a data-adaptive median-split cover, with Ball Mapper as a lens-free comparison, applied at sequence level with placeholder scopes for finer levels.
  • An origami wavelet evaluated against frame theory: it satisfies the upper frame bound (a Bessel sequence) but the lower bound is unestablished; the closest formal home is nonstationary Gabor frames.
  • Spectrogram zeros treated as an analytical object in their own right.

Phase-space attractors

Status: modules written

Each syllable is embedded as a three-dimensional trajectory using Takens delay embedding (delay chosen by average mutual information, dimension reported by false nearest neighbours), rendered as a rotating animation, and compared to other syllables through bottleneck and Wasserstein distances between persistence diagrams. The resulting distance matrix is embedded into a two-dimensional similarity map.

birdsep: source separation

Status: experimental; fine-tuning planned

Separating overlapping calls in field recordings. Conv-TasNet is the default in the Asteroid framework and SepFormer in ESPnet, with several other architectures stubbed for comparison and Bird MixIT checkpoints harvested for filterbank weights. A research thread on zero-conditioning uses a Voronoi tessellation of spectrogram zeros as a conditioning prior, with four falsifiable hypotheses and a batch manifest of seven conditioning variants, alongside a replication of DPTTNet.

Noise labelling and denoising

Status: experimental

Annotation of noise regions inside yaaat and training of denoising models on the labelled regions, together with a signal-to-noise ratio calculator that scans a directory of recordings and reports per-file frame-based estimates.

Community and outreach

Work that faces outward: challenges, proposals, meta-research, and collaboration.

Vocalisation metrics framework paper

Status: drafting sections 4 and 5

A technical paper describing the metrics framework and analysis pipeline, written in collaboration with the Acoustic Research Institute of the Austrian Academy of Sciences in Vienna. An abstract has been submitted to the World Ecoacoustics Congress 2026, and a research visit to Vienna combined with congress attendance has been proposed for funding.

BioDCASE 2026, Task 4: active learning for bioacoustics

Status: scoped

A submission to the active learning task, in which the only editable file is the sampling strategy inside the organisers' framework. The active learning probes built for syllable labelling feed directly into this.

MIREX 2026 proposal: structural transition point detection

Status: full nine-section draft

A proposed challenge task for the Music Information Retrieval Evaluation eXchange, drawing on a parallel life as a musician and composer. The task asks systems to detect points in a composition where a structural transition is viable and to score compatibility between sections at those points, evaluated on spectral, rhythmic, and textural properties rather than tonal function. The stated purpose is to redirect generative music research toward augmenting composers rather than replacing them, and the framing is deliberately independent of any single musical tradition.

The bioacoustics software ecosystem

Status: scraper complete; analysis framework outlined

A GitHub scraper that catalogues bioacoustics repositories by activity rather than popularity, with checkpointed collection, release histories, topic extraction from README files, and a plan to correlate development trends against publication data from OpenAlex.

Nocturnal endemic birds by region

Status: study design

A side study asking which regions have the highest proportion of nocturnal species among their endemic breeding land birds, operationalised against trait databases (EltonTraits, AVONET, AVONICHE) and BirdLife range data, with explicit provenance tags on every diel classification. Motivated by the kiwi, which is one of the few nocturnal ratites.
